Étape 1

Connexions physiques

Avant d'allumer, reliez tous les câbles aux bons connecteurs.

1

Branchement des câbles

  • Microphones → Entrées XLR/TRS (canaux 1 à 16)
  • Clavier / DJ / Ligne → Entrées TRS 6,35 mm (canaux 17 & 18)
  • Enceintes actives / PA → Sorties Main L & Main R (XLR)
  • Moniteurs / Retours → Sorties Aux 1-6 (XLR)
  • Casque → Jack Headphone (TRS 6,35 mm)
  • Ordinateur / DAW → Câble USB Type-B
  • Alimentation → Branchez en dernier, juste avant d'allumer

Cliquez pour fermer ✕
💡
Astuce : La MR18 accepte des signaux équilibrés ET non équilibrés sur toutes les entrées XLR/TRS combo.
Étape 2

Allumer & configurer le Wi-Fi

La MR18 intègre un routeur Wi-Fi tri-mode : pas besoin de routeur externe.

2

Activation du réseau

  1. Appuyez sur POWER (arrière). La LED verte clignote puis reste fixe.
  2. Placez l'interrupteur REMOTE sur ACCESS POINT.
  3. (Première fois) Maintenez RESET 2 secondes avec un trombone pour réinitialiser le réseau.
  4. La console crée son propre réseau : MR18-XX-XX-XX (basé sur l'adresse MAC).
⚠️
Important : Après un changement de nom de réseau ou de mot de passe, passez le switch REMOTE sur ETHERNET, attendez 2 secondes, puis retournez sur ACCESS POINT pour redémarrer le Wi-Fi.
Étape 3

Connecter l'application

La MR18 se contrôle entièrement depuis une tablette, un smartphone ou un ordinateur.

3

Étape 4

Réglage du gain d'entrée

Un bon gain d'entrée est la base d'un mix propre. Visez -6 dBFS sur les crêtes.

4

Input Gain & Phantom Power

  1. Dans l'app, ouvrez le Channel Strip du canal → onglet Input.
  2. Activez 48V (Phantom Power) si vous utilisez un micro condensateur.
  3. Faites tourner la molette GAIN jusqu'à ce que le VU-mètre atteigne ≈ -6 dBFS sur les crêtes.
  4. Activez le HPF (filtre passe-haut) à 80-120 Hz pour les voix.
-6 dBFS
Cliquez pour simuler un signal
⚠️
Attention : N'activez le phantom 48V que sur les canaux qui en ont besoin (condensateurs). Débranchez les micros dynamiques avant d'activer le 48V pour éviter les pops.
Étape 4B

Choisir la source : Physique ou USB

Chaque tranche (channel strip) traite une seule source à la fois. Vous pouvez alimenter un canal soit par une entrée physique (XLR/TRS), soit par un signal USB provenant de votre DAW.

4B

Comprendre la tranche & basculer la source

La tranche (channel strip) est la chaîne de traitement complète d'une source audio : gain → gate → EQ → dynamics → pan → fader → envois. Chaque canal en a une. Le choix de la source se fait via l'interrupteur MIC / USB dans l'onglet Input.

Pour basculer un canal en mode USB :

  1. Ouvrez le Channel Strip du canal concerné → onglet Input.
  2. Cliquez sur l'interrupteur MIC / USB → sélectionnez USB.
  3. La molette Mic Gain est remplacée par USB Trim (±15 dB).
  4. Vérifiez que la piste USB correspondante est bien routée (par défaut 1:1, modifiable via Routing).
  5. Réglez le USB Trim pour atteindre ≈ -6 dBFS sur les crêtes.
Bascule MIC/USB sur la tranche – seul un signal passe à la fois
📡
Routage USB flexible : Par défaut, USB Out 1 → Canal 1, USB Out 2 → Canal 2, etc. (1:1). Pour changer, allez dans Routing (icône flèches en haut de l'écran principal) et réassignez les points orange. Utile pour envoyer un stereo pair de votre DAW sur les canaux 17/18 par exemple.
⚠️
Attention : Le gain analogique (Mic Gain) et le trim numérique (USB Trim) sont indépendants mais un seul est actif selon la position du switch. Pensez à baisser le fader avant de basculer pour éviter un pic de volume.
Étape 5

Mixer & envoyer vers les enceintes

Le fader Main contrôle le niveau global. Les Aux alimentent les retours et moniteurs.

5

Écran de mixage

  • Fader canal → Ajuste le niveau de chaque source.
  • Fader Main L/R → Niveau global envoyé aux enceintes.
  • Aux 1-6 → Envois vers retours / moniteurs.
  • Mute (rouge) → Coupe instantanément un canal.
  • Solo (jaune) → Écoute un canal seul au casque.

T-30

Arrivée sur site – Câblage (10 min)

1
Placez la MR18 sur un rack ou table stable, à l'abri de la pluie. Connectez le câble USB vers le laptop (musique).
2
Micros → XLR :
  • Commentateur (condensateur) → CH1 XLR
  • Présentatrice A (dynamique) → CH2 XLR
  • Présentatrice B (dynamique) → CH3 XLR
3
Retours → Aux :
  • Casque Présentatrice A → Aux 1 (XLR)
  • Casque Présentatrice B → Aux 2 (XLR)
4
PA → Main : Enceinte L → Main L (XLR), Enceinte R → Main R (XLR).
5
Alimentation en dernier → Bouton POWER → LED verte fixe. ✅
T-20

Wi-Fi + App – Configuration (8 min)

1
Switch REMOTE → ACCESS POINT. Votre tablette détecte le réseau MR18-XX-XX-XX. Connectez-vous.
2
Ouvrez MX-Mix → la MR18 apparaît → Connect. L'interface se charge.
3
Configurez le canal musique : Ouvrez CH4 → Input → basculez sur USB. Le signal de votre DAW arrive sur ce canal.
T-12

Gains + EQ – Ajustement (7 min)

1
CH1 (Commentateur – condensateur) :
  • Activez 48V ⚡
  • GAIN → crêtes à -6 dBFS (parlez normalement)
  • HPF à 80 Hz (coupe le vent)
  • EQ : léger boost à 3 kHz (présence voix)
2
CH2 & CH3 (Présentatrices – dynamiques) :
  • Pas de 48V (dynamiques !)
  • GAIN → -6 dBFS sur les crêtes
  • HPF à 100 Hz
  • EQ : cut à 200 Hz (boue), boost léger 5 kHz
3
CH4 (Musique USB) :
  • USB Trim → -12 dB (la musique doit rester en fond)
  • Pan : Centre
  • Ajoutez un léger Reverb (moteur FX 1) pour la spatialisation
T-5

Retours + Auto-Mix – Finalisation (5 min)

1
Retours casque :
  • Aux 1 : envoyez CH2 (Prés. A) à 100% + CH4 (musique) à 30%
  • Aux 2 : envoyez CH3 (Prés. B) à 100% + CH4 (musique) à 30%
  • Pré-réglage : les présentatrices entendent leur voix + un peu de musique
2
Auto-Mix (Dugan) : Activez sur CH1, CH2, CH3. Les 3 micros s'atténuent automatiquement quand quelqu'un parle — parfait pour éviter les chevauchements.
3
Fader Main : Montez progressivement. Testez avec le public en place : le commentateur doit être clair au-dessus de la musique.

🚨
Problème fréquent sur voie publique : Le vent crée un bruit de fond sur le micro condensateur (CH1).
Solution : Montez le HPF à 120 Hz, activez le Gate (seuil -40 dB, release 50 ms) et placez une mousse anti-vent. Si ça persiste, passez le commentateur sur un micro dynamique (CH2) et libérez le 48V.
